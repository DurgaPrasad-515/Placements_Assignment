# Placement Assignment - Polynomial Secret Recovery

## Description

This project solves the Placement Assignment problem using JavaScript (Node.js).

The program:

* Reads test case data in JSON format
* Converts values from different number bases to decimal
* Uses Lagrange Interpolation
* Finds the constant term (secret) of the polynomial
* Supports large numbers using JavaScript BigInt

## Language Used

JavaScript (Node.js)

## How to Run

Open the terminal inside the project folder and run:

```bash
node solution.js
```
